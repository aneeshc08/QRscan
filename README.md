# QRscan

On Screen QR Code Reader

## About
I will be using JavaScript for this project.

The goal is to solve a simple problem: if there's a QR code on your laptop screen, you'd normally have to pull out your phone, scan the screen, and open the link there. My browser extension will let you scan the QR code directly on your screen instead.
